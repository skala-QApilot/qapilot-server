## 1. 정책 개요

NOVA Mobile은 무선 통신 서비스를 제공하는 사업자이며, 본 정책은 NOVA Self-Care 채널에서 고객이 직접 선택·변경할 수 있는 **요금제·부가서비스의 카탈로그**와 **가입·변경·해지·청구의 운영 룰**을 정의한다. 본 정책은 셀프케어 채널의 화면·서버·데이터베이스 시드의 단일 진실 공급원(Single Source of Truth)이며, 구현체와 본 문서가 어긋나는 경우 본 문서가 우선한다.

### 1.1 적용 범위

| 적용 | 미적용 |
|------|--------|
| 무선 데이터·음성 단일 회선 | 결합 회선, 인터넷·IPTV |
| 개인 고객 (B2C) | 법인 고객 (B2B) |
| 신규 가입·요금제 변경·해지 | 단말 할부, MVNO 위탁 |
| 셀프케어 채널 | 영업점·콜센터 채널 (별도 정책) |

### 1.2 가격 표시 원칙

- 모든 가격은 **부가가치세 포함 월정액(KRW)** 으로 표시한다.
- 일할 계산은 본 정책의 범위 밖이며, 청구는 월 단위로 수행한다.
- 약정 할인·결합 할인은 본 버전에서 지원하지 않는다.

## 2. 요금제 카탈로그

본 카탈로그에 등재된 요금제만이 고객에게 노출되며, 이외의 가격·구성은 사용되지 않는다.

| 코드 | 요금제명 | 월 요금 | 데이터 | 음성(분/월) | 문자(건/월) | 분류 |
|------|----------|--------:|-------:|------------:|------------:|------|
| `5G_LITE` | 5G Lite 5GB | 33,000원 | 5GB | 100 | 100 | 5G 입문형 |
| `5G_STANDARD` | 5G Standard 30GB | 55,000원 | 30GB | 300 | 200 | 5G 대중형 |
| `5G_PREMIUM` | 5G Premium Unlimited | 89,000원 | 무제한 | 무제한 | 무제한 | 5G 최상위 |
| `LTE_BASIC` | LTE Basic 3GB | 25,000원 | 3GB | 100 | 100 | LTE 가성비 |
| `LTE_FAMILY` | LTE Family 50GB | 66,000원 | 50GB | 500 | 300 | LTE 다량 사용자 |

> "무제한"은 시스템상 999GB 이상의 데이터 제공량을 의미한다. 음성·문자 무제한은 사용량을 누적 표기만 하며 차감하지 않는다.

### 2.1 요금제 활성화 상태

| 상태 | 의미 |
|------|------|
| 활성 (`is_active=true`) | 고객 카탈로그에 노출되며 신규 가입·변경 대상에 포함 |
| 비활성 (`is_active=false`) | 고객 카탈로그에서 제외되며 신규 가입·변경·예약 시 거부됨. 이미 가입된 회선은 보존되며 별도 안내 없이 유지 |

상품기획팀은 요금제 단종 시 비활성 상태로 전환하며, 비활성 요금제로의 신규 가입·변경 요청은 시스템이 자동 거부한다.

| 변경 시 처리 | 요금제 즉시 변경 또는 변경 예약 자동 적용 시 신규 회선이 발급되며, 신규 회선의 부가서비스 선택은 모두 OFF 상태로 시작한다. 변경 후 카탈로그가 다르므로 명시적 재선택을 요구한다 |
| 토글 권한 | 활성 회선(`CONFIRMED`)에 한해 토글 가능하며 해지 회선의 부가서비스는 변경할 수 없다 |
| 매칭 검증 | 토글 대상 부가서비스는 회선의 현재 요금제 카탈로그(§3.1~§3.5)에 매칭된 항목이어야 한다. 다른 요금제의 부가서비스 ID로 토글을 시도하는 경우 시스템이 자동 거부한다 |
| 단종 처리 | 부가서비스 카탈로그에서 항목이 제거되면 해당 항목의 모든 고객 선택은 함께 삭제된다 |

## 4. 사용량 제공 기준

본 절은 §2 카탈로그의 데이터·음성·문자 제공량을 청구 주기 기준으로 어떻게 계산하는지에 대한 기준을 정의한다.

### 4.1 청구 주기

- 매월 **1일 0시 ~ 말일 24시** (KST 기준)
- 사용량 카운터는 청구 주기 시작일에 0으로 리셋된다.
- 미사용 잔여량은 익월로 이월되지 않는다.

### 4.2 데이터 제공량

| 요금제 | 제공량 | 처리 방식 |
|--------|--------|-----------|
| 5G Lite | 5GB | 소진 시 속도 제한(QoS Throttling) 후 사용 가능 |
| 5G Standard | 30GB | 소진 시 속도 제한 후 사용 가능 |
| 5G Premium | 무제한 | 속도 제한 없음 (테더링 한도는 별도 정책) |
| LTE Basic | 3GB | 소진 시 속도 제한 후 사용 가능 |
| LTE Family | 50GB | 소진 시 속도 제한 후 사용 가능 |

> 데이터 잔여량 표시는 GB 소수점 첫째 자리까지 노출한다(예: `12.4GB`).

### 4.3 음성·문자 제공량

| 요금제 | 음성(분) | 문자(건) | 비고 |
|--------|---------:|---------:|------|
| 5G Lite | 100 | 100 | 초과 시 종량 과금 |
| 5G Standard | 300 | 200 | 초과 시 종량 과금 |
| 5G Premium | 무제한 | 무제한 | 음성·문자 모두 종량 과금 없음 |
| LTE Basic | 100 | 100 | 초과 시 종량 과금 |
| LTE Family | 500 | 300 | 초과 시 종량 과금 |

종량 과금 단가는 본 정책 범위 밖이며 별도 종량 단가표를 따른다.

### 4.4 비활성 회선의 사용량

회선이 해지(`CANCELLED`)되거나 활성 회선이 없는 고객의 사용량 화면은 빈 상태를 표시한다.

## 5. 가입 정책

### 5.1 가입 자격

| 조건 | 내용 |
|------|------|
| 회원 가입 | 셀프케어 채널의 회원가입을 완료한 고객만 가입 신청이 가능하다 |
| 동시 보유 회선 | 회선당 활성 요금제 1건. 한 고객이 동시에 여러 활성 회선을 보유할 수 없다 |
| 미성년자 | 본 버전에서는 별도 검증을 수행하지 않는다. 미성년자 보호 정책은 청소년 요금제 도입 시 별도 약관 적용 |

### 5.2 가입 처리

| 항목 | 내용 |
|------|------|
| 신청 화면 | `/order/new?plan_id={id}` |
| 처리 결과 | 회선이 즉시 `CONFIRMED` 상태로 생성되며 월 요금이 산정된다 |
| 거부 사유 | (1) 이미 활성 회선 보유 → 변경 흐름으로 안내, (2) 비활성 또는 미존재 요금제 → 거부, (3) 미인증 상태 → 로그인 요구 |

### 5.3 단일 회선 정책

NOVA Mobile 셀프케어 채널은 회선당 활성 요금제 1건 모델을 채택한다. 이는 다음을 의미한다.

- 활성 회선이 있는 고객의 신규 가입 요청은 거부되며, 시스템은 변경 흐름으로 자동 안내한다.
- 추가 회선이 필요한 고객은 영업점·콜센터 채널을 이용한다(본 채널 범위 밖).

## 6. 요금제 변경 정책

### 6.1 변경 유형

| 유형 | 시점 | 처리 방식 |
|------|------|-----------|
| 즉시 변경 | 요청 즉시 | 회선의 요금제·월 요금이 즉시 갱신되며, 기존 부가서비스는 초기화 |
| 변경 예약 | 미래 적용일 | 적용일 도래 시 시스템이 자동 적용. 적용 시점은 §6.4 참조 |

### 6.2 즉시 변경 룰

| 룰 | 내용 |
|----|------|
| 적용 대상 | 활성(`CONFIRMED`) 회선에 한함 |
| 처리 방식 | 기존 회선을 해지(`CANCELLED`) 처리하고 신규 요금제의 신규 회선(`CONFIRMED`)을 발급한다. 회선 식별자는 변경 시점마다 갱신된다 |
| 이력 보존 | 기존 회선은 삭제되지 않고 해지 이력으로 보존된다. 회원은 셀프케어 화면에서 변경 이력을 확인할 수 있다 |
| 동일 요금제 | 거부 ("이미 이용 중인 요금제입니다") |
| 비활성 요금제 | 거부 |
| 부가서비스 | 신규 회선의 부가서비스는 OFF 상태로 시작. 신규 요금제의 카탈로그에서 재선택 필요 |
| 기존 변경 예약 | 즉시 변경 시 동시 삭제 |
| 일할 계산 | 미적용. 변경된 월 요금은 다음 청구 주기부터 반영 |

### 6.3 변경 예약 룰

| 룰 | 내용 |
|----|------|
| 적용일 | 오늘 이후 일자만 허용. 오늘 또는 과거 일자 거부 |
| 회선당 예약 수 | 활성 예약 1건. 신규 예약 등록 시 기존 예약을 덮어쓴다 |
| 동일 요금제 예약 | 현재 이용 중인 요금제와 동일한 요금제로의 예약은 거부 |
| 비활성 요금제 예약 | 거부 |
| 자동 적용 | §6.4 참조 |
| 해지 시 처리 | 회선 해지 시 활성 예약은 동시 삭제 |
| 즉시 변경 시 처리 | 즉시 변경 수행 시 활성 예약은 동시 삭제 |

### 6.4 예약 자동 적용

변경 예약은 별도 배치 스케줄러를 통해 적용되지 않으며, **고객이 셀프케어 채널의 인증 화면에 접속하는 시점**에 시스템이 자동으로 처리한다.

| 단계 | 처리 |
|------|------|
| 1. 식별 | 적용일이 오늘 이하인 고객 본인의 변경 예약을 모두 조회 |
| 2. 검증 | 신규 요금제가 활성이고 회선이 활성인 경우에만 적용 |
| 3. 적용 | 기존 회선을 해지(`CANCELLED`) 처리하고 신규 요금제의 신규 회선을 `CONFIRMED` 상태로 발급. 신규 회선의 부가서비스는 OFF 상태로 시작 |
| 4. 폐기 | 신규 요금제가 비활성이거나 회선이 해지된 경우 적용 없이 예약 삭제 |
| 5. 정리 | 처리된 예약 레코드는 삭제 |

> 고객이 적용일 이후 장기간 미접속한 경우에도, 다음 접속 시점에 일괄 반영되며 청구는 적용 시점이 속한 청구 주기부터 신규 요금으로 산정된다.

## 7. 해지 정책

| 항목 | 내용 |
|------|------|
| 해지 신청 | `/orders/{id}` 회선 상세 화면의 "해지하기" |
| 처리 결과 | 회선 상태가 `CANCELLED`로 전환. 활성 변경 예약은 동시 삭제 |
| 부가서비스 | 해지 회선의 부가서비스 토글은 거부 |
| 청구 | 해지 시점이 속한 청구 주기까지의 사용 요금은 정상 청구 |
| 재가입 | 해지 후 재가입을 원하는 경우 신규 가입 흐름을 사용. 기존 해지 회선은 이력으로 보존 |
| 위약금·약정 | 본 버전에서는 약정 정책을 적용하지 않으므로 위약금 없음 |

## 8. 청구 정책

### 8.1 청구 산정

- 청구 금액 = 요금제 월 요금 × 1
- 부가서비스는 별도 요금이 부과되지 않는다(요금제 가격에 포함된 혜택).
- 종량 통화·문자 초과 사용분은 별도 종량 단가표를 따르며 본 정책의 범위 밖이다.

### 8.2 청구 주기 및 결제일

| 항목 | 내용 |
|------|------|
| 청구 주기 | 매월 1일 ~ 말일 (사용량 산정 기준) |
| 결제일 | 회원의 가입일 일자(day)를 매월 결제일로 한다. 자동이체로 청구한다 |
| 월말일 처리 | 가입일이 31일이고 다음 결제월이 30일까지인 경우 등, 해당 월에 가입일과 동일한 일자가 없으면 그 달의 마지막 일자로 결제일을 적용한다 (예: 가입일 31일 → 2월 28일/29일, 4·6·9·11월 30일) |
| 결제 실패 | 익월 5일 재시도. 재차 실패 시 회선 일시 정지 절차(별도 정책) |

### 8.3 청구 이력 노출

셀프케어 채널의 청구 화면은 다가오는 결제 예정월을 포함한 최근 4개의 결제월을 청구 이력으로 노출한다. 첫 행은 다가오는 결제 예정월의 "납부 예정" 상태, 나머지는 직전 월들의 "납부 완료" 상태로 표기된다. 회원 가입 이전의 결제월은 노출되지 않으므로, 가입한 지 1~3개월 미만인 회원의 청구 이력은 노출되는 행 수가 4건 미만일 수 있다.

### 8.4 결제수단

| 항목 | 내용 |
|------|------|
| 등록 결제수단 | 본 채널은 사전 등록된 결제수단(카드 라벨)을 표시만 한다. 결제수단 등록·변경은 콜센터 채널 |
| 자동이체 | 모든 회선에 기본 ON. 개별 OFF는 본 채널 범위 밖 |
| 다음 달 예상 금액 | 활성 변경 예약이 있는 경우 신규 요금제 가격을 다음 달 예상 금액으로 표시 |
